## 2. 발견된 문제점 및 불필요한 파일 (정리 권장 대상)

### 🔴 [1] `07_Test` 폴더의 비대화 및 방치

가장 시급하게 정리해야 할 부분입니다. `Assets/07_Test` 폴더 내부에 정식 빌드에 포함되지 않아야 할 무수한 테스트 잔재가 남아 있습니다.

- **불필요한 테스트용 그래픽 리소스**: 수십 개의 임시 텍스처(`.png`), 그리고 에디터 빌드/런타임에 영향을 줄 수 있는 원본 소스 파일(`.aseprite`)이 여전히 들어 있습니다. (예: `Battle status.aseprite`, `menu tab.aseprite` 등)
- **테스트 씬 및 잡다한 프리팹**: `FogTest`, `Ui_Test` 등 테스트 씬과 찌꺼기 프리팹들이 잔존합니다.
- **조치 권장**:
    1. 원본 디자인 소스(`.aseprite`)는 Unity 프로젝트 내부 `Assets` 폴더가 아닌 외부 작업 폴더로 격리할 것.
    2. `07_Test` 폴더를 통째로 별도의 `.asmdef` (Assembly Definition)로 묶어 정식 릴리즈 빌드에서 스크립트가 완전히 배제되게 하거나, 필요한 것만 남기고 삭제해야 합니다.

### 🟡 [2] 인코딩 (CRLF / LF) 경고 및 로그 파일 Git 추적

- 최근 Git Diff 과정에서도 `Logs/shadercompiler-UnityShaderCompiler.exe0.log`와 같은 자동 생성 로그 파일이 Git 추적 대상에 잡히며 CRLF 경고를 발생시켰습니다.
- **조치 권장**: `.gitignore` 파일을 재점검하여 `Logs/`, `Temp/`, `Library/` 등의 폴더가 확실히 무시되도록 처리해야 합니다.

### 🟡 [3] 기존 `Documentation` 리포트 대비 미해결 구조 및 기술 부채

이전에 작성된 `Lemegeton_Analysis_Report.md`의 경고(Warning) 항목들이 아직 일부 소스코드에 남아있을 확률이 높습니다.

1. **과도한 싱글톤(Singleton)**: `MapManager`, `BattleManager` 등 20여 개 이상의 싱글톤과 `DontDestroyOnLoad` 객체가 혼재함. (씬 재진입 시 생명주기 꼬임 빈발 원인)
2. **async void 패턴 사용**: `IEnumerator` 코루틴과 `async/await` 패턴이 혼재되어 있으며, `async void`로 인해 예외(Exception)가 삼켜지는 잠재적 버그 요인이 있습니다.

## 3. 요약 및 향후 액션 플랜 (Action Plan)

프로젝트 자체의 설계(ATB 턴제 전투, 데이터 주도형 설계, SO 활용)는 인디 레벨에서 매우 우수하고 체계적입니다. 그러나 **"프로젝트 최적화 및 청소"** 단계가 필요합니다.

1. **파일 청소 (Clean-up)**
    - `07_Test` 폴더의 리소스를 전면 압축/백업 후 프로젝트에서 제거.
    - `Assets/04_Art` 내부에도 섞여 있을 수 있는 `.aseprite` 원본 파일 제거 (용량 및 빌드 타임 최적화).
2. **Git 환경 정비**
    - `.gitignore` 최신화 (Logs 폴더 등 자동 생성 파일 배제).
3. **코드 레벨 안정화**
    - 앞서 완료한 '전장의 안개' 및 '포탈 동기화' 픽스처럼, 방어적 코드(Null Check) 및 라이프사이클(Start/Update/OnDestroy) 누수 점검을 주기적으로 진행해야 합니다.
