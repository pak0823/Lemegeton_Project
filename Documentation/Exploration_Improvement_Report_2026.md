# 탐험 씬 기능 개선 작업 보고서 (2026-02-20)

## 1. 개요

본 문서는 탐험 씬에서 발생했던 주요 이슈들(전투 종료 후 씬 전환, 아이템 제작 UX, 타일 이동 판정 및 클릭 정확도)을 개선한 작업의 결과, 트러블 슈팅 과정, 그리고 기술적 변경 사항을 정리한 보고서입니다.

## 2. 주요 개선 사항

### 2.1 전투 패배 시 타이틀 화면 이동

- **기존**: 전투 패배 시 해당 탐험 씬의 마지막 저장 지점으로 복귀.
- **변경**: `BattleManager`에서 패배 확정 시 `SceneTransitionManager`를 통해 타이틀 화면(`TitleScene`)으로 이동하도록 수정.
- **목적**: 로그라이크 또는 던전 탐험 게임의 긴장감 유지 및 명확한 게임 오버 처리.

### 2.2 아이템 제작 결과 팝업화

- **기존**: 제작 완료 시 `CampCraftPage` 내부의 패널이 활성화되는 방식.
- **변경**: 독립된 `CraftResultPopup` 프리팹을 사용하여 결과 표시.
- **기능**:
  - 인벤토리 공간 확인 및 경고 메시지 표시.
  - '모두 획득' 및 '포기' 기능 구현.
  - 팝업 활성화 시 `PlayerMovement` 이동 잠금 (캠프 UI 탭 조작은 가능).

### 2.3 벽(Wall) 타일 이동 불가 처리

- **문제**: `PathfindingSystem`이 `Obstacle` 타일맵만 검사하고 `Wall` 타일맵은 검사하지 않아, 물리 충돌체(Collider)가 없는 벽 타일 위로 이동이 가능한 현상 발생.
- **해결**: `IsWalkableCell` 메서드에 `wallMaps` 순회 및 `HasTile` 검사 로직 추가.
- **결과**: Collider 설정 없이도 타일 그림만으로 이동 불가 구역 설정 가능.

### 2.4 타일 클릭 정확도 개선 (Pure Grid Logic)

- **문제**: `TileAnchor`를 사용하여 타일의 Y축을 조정(층 표현)했을 때, 물리 엔진(`Physics2D`) 기반의 마우스 클릭 감지가 시각적 위치와 미세하게 어긋나거나 뒤쪽 타일을 선택하는 문제 발생.
- **해결**: 물리 연산을 배제하고 수학적 계산(Pure Grid Logic)으로 변경.
- **상세 로직**:
  1.  `MapManager`에 등록된 모든 Floor 타일맵 순회.
  2.  각 맵의 `TileAnchor` 값을 역산((`WorldPos - AnchorOffset`)하여 정확한 그리드 좌표 도출.
  3.  해당 좌표에 타일이 존재하는지(`HasTile`) 확인.
  4.  존재한다면 `Sorting Order`가 높은(시각적으로 위에 있는) 타일을 최종 선택.

## 3. 기술적 비교 (타일 클릭 감지)

| 특징              | 기존 방식 (Physics Collision)              | 새로운 방식 (Pure Grid Calculation)               |
| :---------------- | :----------------------------------------- | :------------------------------------------------ |
| **작동 원리**     | 물리 충돌체(Collider) 감지                 | 수학적 좌표 역산 및 타일 존재 확인                |
| **정확도**        | `TileAnchor` 오프셋 반영 시 오차 발생 가능 | **100% 시각적 위치와 일치**                       |
| **우선순위**      | 물리 엔진 반환 순서에 의존 (불확실)        | **Sorting Order / List Index**로 완벽 제어 가능   |
| **필요 컴포넌트** | `TilemapCollider2D` 필수                   | **Collider 불필요** (최적화 이점)                 |
| **비용**          | 물리 엔진 연산 비용                        | 타일맵 순회 연산 비용 (턴제 방식에서 무시할 수준) |

## 4. 결론

이번 개선 작업을 통해 사용자 경험(UX)과 시스템의 정확도가 크게 향상되었습니다. 특히 **Pure Grid Logic** 도입으로 인해 타일맵 구성 시 불필요한 Collider 설정을 제거할 수 있게 되어, 맵 제작의 편의성과 런타임 최적화 효과를 동시에 얻을 수 있습니다.
